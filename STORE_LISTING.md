### English (`en`)

```text
Choose a default model and thinking level for Gemini and apply them automatically when you open gemini.google.com.

FEATURES

• Choose from the models in your Gemini menu. The list updates as new models become available to your account.
• If your preferred model disappears, the extension uses an available model and keeps your thinking level. Models locked to another plan are marked unavailable.
• Save Low, Medium, or High. In Auto mode, your saved level is kept for the next model you choose that supports thinking controls.
• You can still switch models manually in the current tab. Your default applies again when Gemini reloads.
• After applying your settings, the extension returns focus to the prompt, with the cursor at the end of any text already there.
• Open a new Gemini tab with Alt+G (Option+G on macOS). You can change the shortcut in Chrome.

GETTING STARTED

Open Gemini once to load the model list. Click the extension icon and choose your model and thinking level. For automatic selection on future visits, allow the extension to always access gemini.google.com in Chrome's site access settings.

PRIVACY

The extension runs only on gemini.google.com and has no ads or analytics. It does not collect personal data. Chrome can sync your model and thinking preferences if Chrome Sync is enabled.

SUPPORT

Send questions and suggestions to annacodit@gmail.com or open an issue on GitHub.
https://github.com/AnnaCodit/gemini-default-model-selector

This extension is not affiliated with Google. Gemini is a trademark of Google LLC.
```

## Entering the translations in Developer Dashboard

1. Open the existing item in the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole). On the **Package** tab, use **Upload new package** to upload `gemini-default-model-selector-1.5.1.zip`. Its root includes `manifest.json` and `_locales/`.
2. In **Store listing**, set the primary language to English. Select each of the six locale entries and paste the matching **Detailed description** above. Use the Spanish block for both Spanish and Spanish (Latin America and Caribbean).
3. Save the listing draft. Check the title and summary imported from the ZIP and the full description for each language before submitting it.

See Google's [instructions for uploading an update](https://developer.chrome.com/docs/webstore/update#uploading-an-updated-zip-file) and [localizing the store listing](https://developer.chrome.com/docs/webstore/cws-dashboard-listing#localize-your-listing).

## Single purpose

Remember and apply the user's preferred Gemini model and thinking level on gemini.google.com.

## Permission justification

- `storage`: Stores model and thinking preferences in Chrome Sync and keeps the model list and review reminder preference locally.
- `https://gemini.google.com/*`: Reads and operates Gemini's model controls only on Gemini pages.

## Privacy disclosure

The extension does not collect, sell, or transmit personal data. It uses `chrome.storage.sync` for model and thinking preferences and local browser storage for the Gemini model list and review reminder timing and dismissal.

Editable SVG sources for the icon, screenshots, and promotional tile are included under `assets/icons` and `assets/store/source`.

To regenerate all transparent icon sizes (16, 32, 48, and 128 px) from the SVG, run `python assets/icons/render-icons.py`. The script also updates the icon copies used by the screenshot sources.

Both screenshots use the current popup with an example Gemini catalog. The light screenshot shows 4 Neon and High. The dark screenshot shows Auto with Medium saved. The small promotional tile uses the extension icon and a model selection motif.

The screenshots are global English assets for this release.

To regenerate the screenshots and the promotional tile, run:

```powershell
python assets/store/source/render-store-images.py
```

The renderer requires Python with `playwright` and `Pillow`, plus an installed Chrome or Edge browser. It uses an isolated browser with example preferences. It does not connect to the user's Chrome profile or Gemini account.
