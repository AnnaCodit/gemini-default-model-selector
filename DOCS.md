# Техническая документация

Gemini Default Model Selector — расширение Chrome Manifest V3. Оно запоминает модель и уровень рассуждений и применяет их через интерфейс `gemini.google.com`. Репозиторий загружается в Chrome как распакованное расширение. Сборка и зависимости Node.js не нужны.

## Точки входа

| Файл | Ответственность |
|---|---|
| [manifest.json](manifest.json) | Версия, разрешение `storage`, доступ к `https://gemini.google.com/*`, popup, фоновый процесс, сочетание клавиш и загрузка content script. |
| [shared.js](shared.js) | Общие константы, проверка идентификаторов и каталога, нормализация настроек и миграция старых значений. API доступен как `globalThis.GeminiDefaultModelCore`. |
| [popup.html](popup.html), [popup.js](popup.js), [popup.css](popup.css) | Настройки, каталог моделей, статусы сохранения, кнопка открытия Gemini и напоминание об отзыве. |
| [background.js](background.js) | Service worker сохраняет настройки, запускает их применение во вкладке и обрабатывает команду `open-gemini`. |
| [content.js](content.js) | Читает меню Gemini, распознаёт модель и уровень, применяет изменения, подтверждает результат и возвращает фокус в поле запроса. |

## Настройки и сообщения

- `chrome.storage.sync` хранит `model`, `thinkingLevel` (`low`, `medium`, `high`) и совместимое старое поле `extendedThinking`. `normalizeSettings` переносит прежние значения. Режим `auto` сохраняет уровень для следующей модели с поддержкой рассуждений.
- `chrome.storage.local` хранит последний прочитанный `modelCatalog`, время показа отзыва `reviewPromptNextAt` и признак скрытия `reviewPromptDismissed`. Popup запрашивает актуальный каталог активной вкладки сообщением `GEMINI_READ_MODEL_CATALOG` и использует кэш на других страницах.
- При изменении настройки popup отправляет `GEMINI_SAVE_SETTINGS`. Worker ставит запись в очередь, затем отправляет `GEMINI_DEFAULT_MODEL_APPLY` вкладке, которая была активна при получении запроса. Popup игнорирует результаты устаревших запросов.
- Кнопка открывает новую вкладку через `GEMINI_OPEN_NEW_TAB`. Команда `open-gemini` по умолчанию назначена на Alt+G (Option+G на macOS) и вызывает тот же сценарий в worker. При повторных попытках доставки настройки перечитываются.
- На новой странице content script ждёт готовности меню и применяет сохранённый выбор. Стартовое восстановление после позднего сброса ограничено по времени и числу попыток. Ручное изменение или ввод запроса отменяют стартовое восстановление.
- Результаты применения содержат флаги `ok` и `applied`. Ошибки для popup передаются через `messageKey` и при необходимости `substitution`. Popup переводит их по каталогу.

При правках работы с сайтом сохраняйте проверку фактического выбора модели и уровня. Идентификаторы модели берутся из меню, когда доступны. Уровень определяется по позиции и признаку выбора в меню, поэтому переводы popup не участвуют в распознавании элементов Gemini.

## Локализация и предпросмотр

- [`_locales`](_locales) содержит каталоги `en`, `es`, `es_419`, `pt_BR`, `zh_CN` и `ru`. `default_locale` — `en`. Chrome подставляет метаданные манифеста через `__MSG_…__`, а popup получает строки через `chrome.i18n.getMessage`.
- Для текста в HTML используйте `data-i18n`, для доступных имён — `data-i18n-aria-label`. Добавляйте ключи во все каталоги и сохраняйте именованные подстановки. Тесты проверяют наборы ключей, подстановки, соответствие метаданных карточке и равенство `es` и `es_419`.
- `es_419` даёт отдельную локаль карточки для Латинской Америки и Карибского бассейна. Оба каталога содержат один испанский перевод. Полные тексты карточки и порядок их добавления собраны в [STORE_LISTING.md](STORE_LISTING.md).
- Для предпросмотра установите `DEBUG = 1` в [shared.js](shared.js), перезагрузите расширение на `chrome://extensions` и откройте popup. Селектор загружает выбранный каталог из пакета и запоминает выбор в адресе текущего окна (`previewLocale`). Вариант «Язык браузера» возвращает нативную локализацию Chrome. Язык Chrome, настройки модели и локаль карточки от предпросмотра не меняются.
- `REVIEW_PROMPT_DEBUG = 1` отдельно принудительно показывает напоминание об отзыве. Перед выпуском оба флага должны быть `0`.

## Проверки и выпуск

- `npm run check` проверяет синтаксис и запускает Node-тесты для worker, popup, общих функций и content script.
- `python tests/browser-regression.py` проверяет применение настроек на локальном DOM-макете в изолированном браузере. Понадобятся Python Playwright и Chrome или Edge.
- `python assets/store/source/render-store-images.py` обновляет англоязычные изображения для магазина. Понадобятся Python Playwright, Pillow и Chrome или Edge.
- Версия синхронизируется в `manifest.json` и `package.json`. История релизов ведётся в [CHROMEWEBSTORE.md](CHROMEWEBSTORE.md). В ZIP для магазина входят манифест, JS/CSS/HTML расширения, PNG-иконки и `_locales/`.
