# Gemini Default Model Selector

Расширение Chrome запоминает выбранную модель Gemini и состояние `Extended thinking`, а затем автоматически восстанавливает их на `gemini.google.com`.

## Возможности

- выбор `3.5 Flash-Lite`, `3.6 Flash` или `3.1 Pro`;
- отдельный переключатель `Extended thinking`;
- синхронизация настроек через Chrome Sync;
- однократное применение после загрузки страницы без перезаписи последующего ручного выбора;
- повторное применение при явном изменении настроек в popup расширения;
- подтверждение каждого переключения, стабилизационная пауза и ограниченный повтор при задержках интерфейса Gemini;
- языконезависимое обнаружение `Extended thinking` по семантической структуре меню;
- проверка Extended-состояния непосредственно на кнопке без повторного открытия и мигания меню;
- один стартовый цикл применения без накопления повторов от DOM-обновлений Gemini;
- одна команда применения из popup без дублирования через событие Chrome Sync;
- восстановление фокуса и позиции каретки в поле запроса после переключения;
- светлая и тёмная темы, доступное управление с клавиатуры;
- только одно разрешение API (`storage`) и доступ только к `gemini.google.com`.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку этого проекта.
5. Обновите уже открытую вкладку Gemini один раз.

После установки нажмите значок расширения и выберите параметры. Изменения сохраняются и применяются автоматически.
