# Gemini Default Model Selector

Расширение Chrome запоминает выбранную модель Gemini и уровень мышления (`Low`, `Medium`, `High`), а затем автоматически восстанавливает их на `gemini.google.com`.

## Возможности

- выбор `3.5 Flash-Lite`, `3.8 Flash`, `3.1 Pro`, `4 Argon` или `4 Carbon`;
- поддержка нового меню с описанием перед названием модели и прежнего порядка подписей;
- точное распознавание названий моделей без совпадений с Profile, Prompt и похожими словами;
- поиск переключателя рядом с полем ввода и отказ от выбора при неоднозначности;
- приоритет связанного или точно обозначенного меню Gemini перед эвристическим поиском;
- недоступные на аккаунте модели с замком или признаком блокировки не нажимаются; popup сообщает об ограничении и предлагает выбрать другую модель;
- автоматический фоллбэк на `3.7 Flash`, если Google ещё постепенно раскатывает `3.8 Flash` и он пока недоступен в интерфейсе;
- выбор одного из трёх уровней мышления;
- поддержка вложенного меню уровней мышления: открытие кликом или наведением, без повторного открытия для проверки результата;
- совместимость со старым переключателем `Extended thinking`: `Low` выключает его, `Medium` и `High` включают;
- перенос прежних настроек: выключенный `Extended thinking` становится `Low`, включённый — `High`;
- открытие новой активной вкладки Gemini сочетанием `Alt+G` (`Option+G` на macOS);
- автоматическое применение настроек и фокусировка родного поля запроса в новой вкладке;
- отображение фактически назначенного хоткея и переход к его изменению или отключению в настройках Chrome;
- синхронизация настроек через Chrome Sync;
- применение после загрузки страницы и одно исправление позднего сброса Gemini в течение следующих 5 секунд; любой ручной ввод сразу отменяет это восстановление;
- ожидание медленно загружающихся кнопок, моделей и уровней мышления до 30 секунд при старте;
- выбор новой модели не зависит от наличия уровней мышления у предыдущей модели;
- повторное применение при явном изменении настроек в popup расширения;
- закрытие меню через Escape с ожиданием его исчезновения, единая проверка устойчивости модели и уровня в течение 200 мс и ограниченный повтор при сбое;
- языконезависимый выбор уровня по позиции и признаку выбранного пункта в меню;
- проверка после клика по индикатору на кнопке: подпись сравнивается с выбранным пунктом только в текущем применении, без словаря переводов и кэша названий;
- меню остаётся видимым; при смене модели вложенные уровни проверяются уже у новой модели, проверка результата после выбора уровня не открывает меню повторно;
- один стартовый цикл и не более одного восстановления после позднего сброса, без накопления повторов от DOM-обновлений Gemini;
- одна команда применения из popup без дублирования через событие Chrome Sync;
- сохранение выбора фоновым процессом сразу после изменения, даже если popup уже закрыт; быстрые изменения сохраняются по порядку;
- возврат фокуса в поле запроса с кареткой в конце актуального текста после переключения;
- возврат фокуса не отбирает его у панели расширения, адресной строки или другой вкладки;
- поиск поля запроса по структуре композитора без зависимости от английской подписи или Quill;
- светлая и тёмная темы, доступное управление с клавиатуры;
- только одно разрешение API (`storage`) и доступ только к `gemini.google.com`.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку этого проекта.
5. Обновите уже открытую вкладку Gemini один раз.

После установки нажмите значок расширения и выберите параметры. Изменения сохраняются и применяются автоматически.

Для автоматического выбора в новых вкладках Chrome должен постоянно разрешать расширению доступ к `https://gemini.google.com/*`. Откройте **Расширения → Gemini Default Model Selector → Сведения → Доступ к сайтам** и включите доступ к Gemini. При доступе только по нажатию значка расширение запускается в текущей вкладке после нажатия; новая вкладка снова остаётся без автоматического применения. Разрешение настраивается отдельно для каждого профиля Chrome и для магазинной и распакованной копий расширения.

Чтобы быстро начать новый запрос, нажмите `Alt+G` (`Option+G` на macOS). Расширение сразу откроет новую активную вкладку Gemini, применит выбранные настройки и установит фокус в родное поле запроса. Уже открытые диалоги и неотправленные черновики не изменяются.

Горячую клавишу можно изменить или отключить на странице `chrome://extensions/shortcuts` либо через кнопку **Change** в popup.
