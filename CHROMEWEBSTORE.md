# Chrome Web Store — Gemini Default Model Selector

Last Updated: 2026-11-21

Основной язык карточки — английский. [STORE_LISTING.md](STORE_LISTING.md) содержит локализованные названия, краткие и полные описания, шаги для Developer Dashboard, обоснования разрешений и ссылки на изображения. [Политика конфиденциальности](PRIVACY_POLICY.md) хранится отдельно.

## Version History

| Version | Date | Changes | Status |
|---|---|---|---|
| 1.5.1 | 2026-11-21 | Русский перевод popup и карточки Chrome Web Store. В режиме отладки можно просматривать popup на пяти языках. | Draft |
| 1.5.0 | 2026-11-21 | Popup и карточка Chrome Web Store на английском, испанском, португальском (Бразилия) и упрощённом китайском. Для испанского в магазине подготовлены два языковых варианта с одинаковым текстом. | Draft |
| 1.4.1 | 2026-11-21 | В окне расширения появится предложение оставить отзыв. Его можно отложить на неделю или скрыть навсегда. | Draft |

| 1.3.12 | 2026-11-15 | Повторы открытия меню и применения после временных сбоев; подтверждение reasoning для новой модели; ожидание выбора до закрытия меню; два ограниченных восстановления при загрузке; актуальные настройки при доставке новой вкладке. | Draft |
